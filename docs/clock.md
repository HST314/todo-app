# 置顶时钟与提醒

## 打开与关闭

点击顶栏「置顶时钟」：

- 浏览器支持 Document Picture-in-Picture 时，会打开一个**始终置顶**的小窗；
- 不支持时会降级为普通弹窗（无法保证置顶），并提示原因；
- 关闭小窗后，时钟 DOM 会回到主页面并隐藏，再次点击可以重新打开。

推荐使用 Chrome / Edge 116+。

## 小窗内容

```text
      09:41:07
     10月30日 周五

今日              3 / 7
进行中 · 写论文初稿
```

从上到下：

| 区域 | 内容 |
|---|---|
| 时间 | `HH:MM:SS`，每秒刷新 |
| 日期 | 月、日、星期 |
| 今日进度 | 已完成 / 总任务数 |
| 状态行 | 进行中的任务、下一项、当前时段剩余等 |

状态行按优先级显示：

1. 有正在进行的精确时间任务：`进行中 · 任务标题`；
2. 有下一项精确时间任务：`下一项 14:00 开组会 · 还有 23 分钟`；
3. 当前时段还有未完成任务：`当前 上午 · 2 项未完成`；
4. 当前时段已清空但今天还有任务：`当前时段已清空 · 今天还有 3 项`；
5. 今天全部完成：`今天全部完成 🎉`；
6. 今天没有任务：`今天暂无待办`。

## 紧凑模式

- 小窗底部「收起」：只保留时间和日期；
- 「展开」恢复完整信息；
- 选择会保存在本地，下次打开沿用；
- 小窗尺寸大约 360×210，紧凑模式 300×130。

## 主题

时钟会跟随主应用的主题（浅色 / 深色 / 跟随系统），小窗内同步切换。

## 任务提醒

### 开启

1. 打开「设置」；
2. 点「授权通知」，允许浏览器通知；
3. 选择提前量：到点提醒、提前 5 / 10 / 15 / 30 分钟；
4. 可选开启「时段任务提醒」。

### 触发规则

- **精确时间任务**：在开始时间减去提前量时触发；
- **时段任务**：开启「时段任务提醒」后，在上午 / 下午 / 晚上开始时触发；
- 每 30 秒检查一次；
- 如果页面在后台一段时间后才恢复，超过开始时间 5 分钟的任务不会补报，避免一次性弹出一堆过期提醒；
- 每个任务每天只提醒一次；
- 提醒同时发系统通知和页面 toast，点击通知会跳到对应日视图。

### 限制

- 通知只在页面或置顶小窗开着时生效；
- 关闭页面后没有后台进程，不会提醒；
- 浏览器权限被拒绝时，提醒不会触发（系统通知和页面 toast 都不会出现）。

## 常见问题

**小窗没有置顶？**
浏览器不支持 Document Picture-in-Picture，已降级为普通窗口。请使用 Chrome / Edge 116+。

**没有收到通知？**
检查设置里的通知权限、任务是否设置了精确时间、页面是否还开着。

**提醒重复？**
提醒记录按天保存在浏览器 localStorage，清理站点数据后会重新提醒一次。
