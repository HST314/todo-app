# 视图与导航

拾光把时间分成三种粒度：月、周、日。三种视图共享同一份 Markdown 数据，只是观察角度不同。

## 月视图

顶部切到「月」，或按 `M`。

- **左侧周号**：`W40`、`W41`…… 是 ISO 周数。点击任意周号进入该周的周视图。
- **日期格**：点击任意日期进入这一天的日视图。
- **红点**：当天还有未完成任务；含高优先级任务时红点会轻微脉冲。
- **灰点**：当天任务全部完成。
- **任务预览**：每格最多显示 3 条任务，超过显示 `+N`；已完成任务排在后面。
- **月度统计**：标题下方显示「X 天有任务 · Y 项未完成」。
- **跨月格子**：上月末/下月初的日期会淡化显示，点击同样可以进入对应日期。

月视图只负责浏览和跳转，不直接创建任务。

## 周视图

顶部切到「周」，或按 `W`。

- **7 列 × 3 行**：周一到周日，上午 / 下午 / 晚上。
- **表头**：点击日期表头进入该日的日视图；聚焦后按 `Enter` 或空格也可以。
- **单元格**：显示该时段的任务卡片、未完成数 / 总数；空白处点击即可速记。
- **分享行高**：同一时段在 7 天里高度一致，方便横向比较。
- **今天**：日期表头和对应单元格会高亮。
- **跨月周**：7 天可能横跨两个月，数据会同时从两个月份的文件夹加载。

周视图适合排一周的节奏，也是跨天拖动的主要场所。

## 日视图

顶部切到「日」，或按 `D`。

- **三个容器**：
  - 上午 06:00–11:59
  - 下午 12:00–17:59
  - 晚上 18:00–05:59
- **计数**：每个容器标题右侧显示「未完成 / 总数」。
- **速记**：点击「＋ 添加任务」或容器空白处。
- **隐藏已完成**：右上角按钮切换；只影响当前页面会话，不影响数据。
- **逾期面板**：如果今天之前还有未完成任务，顶部会出现「逾期未完成 · N 项」：
  - 每条可「改到今天」或「改到明天」；
  - 「全部改到今天」会批量移动所有逾期任务；
  - 最多显示前 8 条，其余只计数；
  - 跨月移动时，任务附件文件夹会一起搬移。

日视图适合专注当天。

## 导航

| 操作 | 结果 |
|---|---|
| `D` / `W` / `M` | 切换日 / 周 / 月视图 |
| `T` | 回到今天 |
| `←` / `→` | 上一天 / 上一周 / 上一月 |
| 点击月视图左侧 `W44` | 进入该周 |
| 点击月视图日期 | 进入该日 |
| 点击周视图表头 | 进入该日 |
| 顶栏 `‹` / `›` | 按当前视图前后翻页 |
| 顶栏「今天」 | 回到当前日期 |

地址栏使用 hash 路由，可以直接收藏或分享到本机：

```text
http://localhost:8000/#/day/2026-10-29
http://localhost:8000/#/week/2026-W44
http://localhost:8000/#/month/2026-10
```

刷新页面会保持当前视图和日期。

## 显示规则

- 任务归属哪个时段，由任务的**时段**或**精确时间的开始时间**决定，不存在小时刻度。
- 精确时间（如 `09:00-11:00`）只是卡片上的标签，不改变日/周视图的布局。
- 晚上时段跨午夜：18:00 到次日 05:59 都算晚上。
- 周视图和日视图的任务排序由 Markdown 中的顺序决定，拖动后会写回文件。
