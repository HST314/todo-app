# 任务管理

一条任务由这些信息组成：标题、状态、时段（可选精确时间）、优先级、类别、备注、附件。

## 新建任务

### 原地速记

在日视图或周视图里：

1. 点击「＋ 添加任务」，或直接点击时段空白处；
2. 输入标题；
3. 选择优先级（默认 `!中`）和类别（记住上次选择）；
4. 按 `Enter` 保存，`Esc` 取消。

速记默认只设置时段。精确时间、备注、附件可以保存后再打开任务详情补充。

### 快捷键

按 `N` 会在当前日期的上午时段打开速记框；在月视图里按 `N` 则定位到今天。

### 默认值

- 优先级：中
- 类别：上次新建任务时选择的类别（保存在本地设置里）
- 时段：你点击的那个容器
- ID：自动生成，形如 `^t-a1b2c3`

## 任务卡片

卡片上显示：

- 左侧复选框：完成状态；
- 标题；
- 精确时间（仅当设置了精确时间）；
- 类别色条和类别名、非中优先级、附件数量；
- 右侧 `⠿`：拖动把手。

点击卡片（复选框和把手除外）打开任务详情。

## 编辑任务详情

详情面板支持修改：

| 字段 | 说明 |
|---|---|
| 标题 | 不能为空；保存时若标题变化，附件文件夹会跟着改名 |
| 日期 | 可以改到任意日期；跨月会搬移附件文件夹 |
| 优先级 | 高 / 中 / 低 |
| 类别 | 来自设置里的类别列表 |
| 时段 | 上午 / 下午 / 晚上 |
| 精确时间 | 可选；勾选后时段由开始时间决定，结束时间可留空 |
| 备注 | 多行文本，保存为任务下方的 `>` 引用行 |
| 附件 | 见 [附件管理](attachments.md) |

### 保存

- 点击「保存」或按 `Ctrl+Enter`；
- 刷新页面或切换视图**不会**自动保存；
- 保存成功后详情面板关闭，列表立即更新。

### 关闭与未保存修改

点击 `✕`、按 `Esc`、点击左侧空白或点「取消」时：

- 没有任何改动：直接关闭；
- 有改动：弹出「未保存的修改」，提供三个选择：
  - **保存**：执行完整保存流程，成功后关闭；
  - **不保存**：丢弃本次修改并关闭；
  - **继续编辑**：留在详情面板。

标题为空、精确时间不合法等校验失败时，面板会保持打开并提示原因。

## 完成与撤销

- 点击卡片左侧复选框切换完成状态；
- 完成后卡片变灰、标题划线，仍可编辑、拖动；
- 操作后底部提示条保留 5 秒「撤销」；
- 右上角「隐藏已完成」可以暂时隐藏它们（仅当前会话）。

## 删除任务

详情面板左下角「删除」：

- 会先弹确认；
- 如果任务带附件：整个任务附件文件夹会被真实删除，**不可撤销**；
- 如果没有附件：删除后 5 秒内可以撤销；
- 删除只改 Markdown 和对应的附件目录，不会影响其它任务。

## 逾期任务

日视图会扫描今天之前所有未完成任务：

- 顶部显示「逾期未完成 · N 项」；
- 可以单条「改到今天 / 改到明天」；
- 也可以「全部改到今天」；
- 移动会保留优先级、类别、备注、精确时间和附件；
- 跨月移动会搬移附件文件夹。

如果不想看到逾期提示，把旧任务完成或挪到今天即可。

## 全局搜索

按 `Ctrl+K` 或 `/` 打开搜索面板。

- 搜索范围：标题、备注、附件文件名、链接地址；
- 过滤器：类别、优先级、状态（未完成 / 已完成）；
- `↑` / `↓` 选择，`Enter` 打开；
- 点击结果会跳到对应日视图，并高亮该任务；
- `Esc` 关闭搜索。

搜索会读取数据目录里的全部日文件，数据量大时首次打开可能需要一两秒。

## 文件被外部修改时

如果你在编辑器里改了当天的 Markdown，而页面里还保留着旧版本，保存时会检测到冲突：

- **重新加载**：丢弃页面里的修改，读取磁盘版本；
- **覆盖磁盘**：用页面里的版本覆盖文件；
- **取消**：不写入，留在当前页面。

冲突检测基于文件的修改时间（mtime），详见 [数据与备份](data.md)。
