# 拖动与排序

拖动用于调整任务的日期、时段和顺序。松开鼠标后立即写入 Markdown，不需要再点保存。

## 怎么拖

1. 按住任务卡片，或右侧的 `⠿` 把手；
2. 移动超过 5 像素才算开始拖动，避免误触；
3. 拖到目标时段/日期，松手；
4. 底部提示条出现「撤销」，保留 5 秒。

拖动过程中按 `Esc` 可以取消，任务会回到原位。

## 支持的范围

| 场景 | 支持 |
|---|---|
| 日视图 · 同时段内调整顺序 | ✅ |
| 日视图 · 上午 ↔ 下午 ↔ 晚上 | ✅ |
| 周视图 · 同时段内调整顺序 | ✅ |
| 周视图 · 同一时段内跨天 | ✅ |
| 周视图 · 跨天且跨时段 | ✅ |
| 跨月拖动（例如 10/31 → 11/1） | ✅ |
| 月视图拖动 | ❌（月视图只用于浏览和跳转） |
| 触屏拖动 | ❌（当前仅适配鼠标/触控板） |

## 跨时段与精确时间

精确时间（`09:00-11:00`）只是标签，不参与布局。把任务拖到另一个时段时：

- 时段会更新为目标时段；
- 精确时间会自动清空，避免出现「晚上 09:00」这种矛盾；
- 5 秒内点「撤销」会恢复原来的时段、顺序和精确时间。

在**同一时段内**排序不会影响精确时间。

## 排序规则

每个时段内的任务顺序就是 Markdown 中任务行的顺序。

- 拖到两张卡片之间：插入到对应位置；
- 拖到列表空白处：放到该时段末尾；
- 保存时按「上午 → 下午 → 晚上」分组，组内保持你拖出来的顺序。

## 跨天与跨月

- **同月跨天**：只改日期，附件文件夹不动（附件按月份存放）。
- **跨月**：先把任务附件文件夹复制到目标月份，Markdown 保存成功后再删除旧文件夹；失败会回滚。
- 如果目标日期已存在同 ID 的任务（例如手动复制过 Markdown），工具会为新任务生成一个新 ID，避免冲突。

## 完成状态

已完成的任务仍然可以拖动和排序，不会自动取消完成状态。

## 撤销

拖动后的提示条保留 5 秒：

- 撤销会恢复原日期、原时段、原顺序；
- 如果跨月移动过附件，撤销会把文件夹搬回去；
- 超过 5 秒后只能手动拖回。

## 实现说明

拖动使用 Pointer Events 手写实现，而不是 HTML5 Drag & Drop：

- 可以精确控制落点、插入位置和视觉反馈；
- 不依赖浏览器对跨容器拖放的支持；
- 在 Chrome / Edge 的桌面端表现一致。
