# 快捷键与鼠标操作

## 全局

| 快捷键 | 作用 |
|---|---|
| `Ctrl+K` / `⌘K` | 打开全局搜索 |
| `/` | 打开全局搜索 |
| `D` | 日视图 |
| `W` | 周视图 |
| `M` | 月视图 |
| `T` | 回到今天 |
| `N` | 在当前日期新建任务（默认上午） |
| `←` / `→` | 上一天 / 上一周 / 上一月 |
| `Esc` | 关闭当前弹层 |

在输入框、下拉框、搜索框或详情面板里打字时，这些单键快捷键不会触发。

## 速记框

| 快捷键 | 作用 |
|---|---|
| `Enter` | 保存任务 |
| `Esc` | 取消 |
| 点击外部 | 取消 |

## 任务详情

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Enter` / `⌘Enter` | 保存 |
| `Esc` | 请求关闭；有未保存修改时弹确认 |
| `Tab` | 在字段间移动 |

## 全局搜索

| 快捷键 | 作用 |
|---|---|
| `↑` / `↓` | 选择结果 |
| `Enter` | 打开选中的结果 |
| `Esc` | 关闭搜索 |

## 拖动

| 操作 | 作用 |
|---|---|
| 按住卡片或 `⠿` 移动 5px | 开始拖动 |
| `Esc` | 取消拖动 |

## 鼠标操作

| 操作 | 结果 |
|---|---|
| 点击月视图日期 | 进入日视图 |
| 点击月视图左侧 `W44` | 进入该周 |
| 点击周视图日期表头 | 进入该日 |
| 点击任务卡片 | 打开详情 |
| 点击复选框 | 完成 / 取消完成 |
| 点击「＋ 添加任务」或时段空白 | 速记 |
| 点击附件行 | 资源管理器定位文件 |
| 点击链接附件 | 浏览器打开链接 |
| 点击「打开文件夹」 | 打开任务附件文件夹 |
| 顶栏「今天」 | 回到今天 |
| 顶栏 `‹` / `›` | 前后翻页 |
| 顶栏「隐藏已完成」 | 切换已完成任务的显示（当前会话） |
| 顶栏主题按钮 `◐` | 循环切换 跟随系统 / 浅色 / 深色 |
| 顶栏「置顶时钟」 | 打开时钟小窗 |
| 顶栏「设置」 | 打开设置 |

## 提醒

提醒没有快捷键，需要在「设置」里：

1. 授权通知；
2. 选择提前量；
3. 可选开启时段提醒。
