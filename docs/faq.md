# 常见问题

## 运行与安装

**为什么必须运行 `python server.py`？**
浏览器拿不到文件夹绝对路径，也不能直接打开资源管理器。没有本地服务，读写和「打开文件夹」都无法工作。

**可以用 `python -m http.server` 吗？**
不行。它没有 `/api/*` 接口，页面会提示无法连接本地服务。

**支持哪些浏览器？**
推荐 Chrome / Edge 116+。置顶时钟依赖 Document Picture-in-Picture；其它 Chromium 浏览器可以正常使用基本功能，但未做完整验证。

**需要什么 Python 版本？**
Python 3.8+，只用标准库。Windows 的目录选择框需要 `tkinter`（官方安装包默认包含）。

**端口被占用怎么办？**

```bash
python server.py --port 8080
```

## 数据与隐私

**数据会上传到云端吗？**
不会。服务只监听本机，页面不加载第三方脚本，也没有统计或遥测。

**数据存在哪里？**
你首次选择的数据目录。结构见 [数据与备份](data.md)。

**怎么备份？**
把数据目录放进 Git，定期提交；或者手动复制整个目录。删除附件是真实删除，Git 是唯一恢复手段。

**能在多台电脑间同步吗？**
没有内置同步。可以用 Git、网盘或同步盘手动同步数据目录，但不要同时运行两个会写入同一目录的实例。

**`config.json` 要提交吗？**
不要。它保存的是本机绝对路径，已加入 `.gitignore`。

**可以直接用编辑器改 Markdown 吗？**
可以。保存时工具会规范化任务顺序，但保留备注、其它小节和未知内容。改完回到页面时如果文件已被外部修改，会触发冲突提示。

## 使用

**任务 ID `^t-xxxx` 是干什么的？**
用于稳定标识任务，改名、改日期、拖动时保持不变，附件文件夹也依赖它。手写时可以省略。

**为什么拖动后精确时间没了？**
跨时段拖动会清空精确时间，避免出现「晚上 09:00」的矛盾。5 秒内撤销可以恢复。

**逾期任务从哪里来？**
今天之前所有未完成任务。日视图顶部可以逐条或批量改到今天。

**为什么拖入附件后不能打开文件夹？**
附件在点保存前只是「待保存」，还没有真正写入磁盘。保存后按钮才会解锁。

**为什么删除附件不可撤销？**
这是有意设计：移除并保存即真实删除文件，避免磁盘里堆积看不见的残留。恢复依赖 Git。

**能改类别和颜色吗？**
可以。设置里可以增删类别、修改颜色。

**能改主题吗？**
顶栏 `◐` 或设置里切换：跟随系统 / 浅色 / 深色。

## 提醒与时钟

**为什么没有收到提醒？**
检查：通知权限是否授权、任务是否设置了精确时间、页面或置顶小窗是否还开着。关闭页面后没有后台进程。

**为什么时钟没有置顶？**
当前浏览器不支持 Document Picture-in-Picture，已降级为普通窗口。请使用 Chrome / Edge 116+。

## 兼容与限制

**旧的 `assets/` 附件还能用吗？**
不兼容。不会迁移、定位或删除；确认不需要后可手动清理。

**支持手机或平板吗？**
暂不支持。界面和拖动针对桌面端鼠标优化。

**支持多个标签页同时编辑吗？**
不建议。可能出现冲突；工具会提示，但最好只开一个页面。

**附件有大小限制吗？**
单个附件上限 2 GB，单个 Markdown 文件上限 32 MB。

**数据文件损坏了怎么办？**
从 Git 恢复上一个版本；Markdown 是纯文本，也可以手动修复。

**为什么 README 里的截图和我看到的不一样？**
截图使用演示数据，主题、缩放和窗口大小可能不同。

## 其它

**有 API 吗？**
本地服务有 `/api/*` 接口，见 [本地服务](server.md)。它们面向页面，不是稳定的公开 API。

**可以在公网部署吗？**
不建议。服务没有多用户鉴权和加密，只适合本机使用。

**许可证？**
项目尚未指定开源许可证，详见 README 末尾。
